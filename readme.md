# Bilişim Vadisi 2026 - Karonext 2

## Proje Hakkında

Bu proje, katılım bankalarının ürün, kampanya ve finansman
bilgilerini yapay zekâ ve doğal dil işleme yöntemleri kullanarak
analiz etmek amacıyla geliştirilmiştir.

Sistem; bankaların resmi internet sitelerinden elde edilen verileri
işleyerek finansman tutarı, vade, kâr payı, kampanya koşulları,
ödüller ve diğer önemli bilgileri standart bir yapıya dönüştürür.
